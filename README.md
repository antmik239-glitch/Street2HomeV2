# Street2Home V2

A welcoming, offline-first Android resource guide. This is a fresh test build, not a production resource directory. Resource entries must be verified before public use.

## Build
GitHub Actions > Build Street2Home V2 APK > Run workflow. Download the `Street2HomeV2-debug-apk` artifact after a successful run.

Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17, compile SDK 35.
